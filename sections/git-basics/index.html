Git and GitHub basics

Git is a distributed version control system. GitHub is a platform that hosts Git repositories and adds collaboration, review, planning, and automation.

Core vocabulary

  • Repository: the project files and their complete history.
  • Commit: a recorded snapshot of changes with a message.
  • Branch: an independent line of development.
  • Clone: a local copy of a remote repository.
  • Pull: bring remote changes into a local repository.
  • Push: send local commits to a remote repository.
Recall prompt: Explain why a team uses commits and branches instead of editing one shared copy of a project.
