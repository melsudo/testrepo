GH-900 / Topic 02

Repositories and structure

A GitHub repository holds the source code, history, documentation, conversations, and contribution rules for a project.

Know these pieces

  • README: the project orientation and getting-started page.
  • .gitignore: patterns for files Git should not track.
  • License: permissions and conditions for using the project.
  • Fork: your own copy of another user's repository.
  • Visibility: public repositories are broadly discoverable; private repositories restrict access.
  • Organization: a shared account for teams, repositories, and permissions.
Recall prompt: When would a fork be useful for contributing to a project you do not own?
