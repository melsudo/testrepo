GH-900 / Topic 04

Planning and collaboration

GitHub gives teams a shared place to discuss work, track decisions, and review changes before they become part of the project.

Choose the right tool

  • Issue: track a task, bug, idea, or piece of work.
  • Discussion: have open-ended conversations and questions.
  • Project: organize work into views, fields, and workflows.
  • Pull request: propose and review a specific code change.
  • Labels and milestones: classify work and group it toward a goal.
Recall prompt: How is a pull request different from an issue?
