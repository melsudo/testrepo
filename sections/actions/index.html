GH-900 / Topic 05

Automation with Actions

GitHub Actions automates work in response to repository events, such as testing a pull request or publishing a release.

Building blocks

  • Workflow: an automated process defined in a YAML file.
  • Event: what starts a workflow, such as a push or pull request.
  • Job: a group of steps that runs on a runner.
  • Step: an individual shell command or reusable action.
  • Runner: the machine that executes a job.
  • Artifact: a file or package produced by a workflow.
Recall prompt: Describe a workflow that runs tests whenever a pull request is opened.
