Branches and GitHub flow

GitHub flow is a lightweight process for making changes safely while keeping work visible to collaborators.

The sequence

  1. Create a branch from the default branch.
  2. Make focused changes and commit them.
  3. Push the branch and open a pull request.
  4. Discuss and review the proposed change.
  5. Resolve feedback and checks, then merge.
  6. Delete the finished branch when appropriate.
