GH-900 / Topic 06

Security and responsible use

Good GitHub security protects accounts, code, dependencies, credentials, and the people who maintain a project.

Controls to recognize

  • Authentication: prove who you are, including with two-factor authentication.
  • Authorization: determine what an authenticated person can do.
  • Least privilege: grant only the access a person or process needs.
  • Secret scanning: detect credentials accidentally committed to a repository.
  • Dependabot: identify and help update vulnerable dependencies.
  • Code scanning: find security issues in source code.
Recall prompt: Why should credentials be stored as secrets instead of committed to source code?
