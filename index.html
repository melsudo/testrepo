The study map

Six areas to make familiar

01

Git and GitHub basics

Understand the difference between the Git version control system and GitHub, the collaboration platform around it.

  • Know: repositories, commits, branches, remotes, clone, pull, push
  • Explain: how Git tracks changes over time
02

Repositories and structure

See a repository as the home for code, history, documentation, issues, and contribution context.

  • Compare: public and private repositories, accounts and organizations
  • Know: README files, licenses, .gitignore, forks, stars, watchers
03

Branches and GitHub flow

Practice the lightweight workflow that keeps changes isolated, visible, and easy to discuss.

  • Sequence: branch, make changes, commit, open a pull request, review, merge
  • Handle: merge conflicts and branch protection expectations
04

Planning and collaboration

Learn how teams turn conversation into visible, trackable work on GitHub.

  • Use: issues, labels, milestones, discussions, and Projects
  • Review: pull request comments, suggested changes, approvals, and conversations
05

Automation with Actions

Get comfortable with the building blocks of GitHub Actions and the reasons teams automate.

  • Know: workflows, events, jobs, steps, actions, and runners
  • Connect: continuous integration, tests, builds, deployments, and artifacts
06

Security and responsible use

Recognize the controls that protect code, credentials, dependencies, and the people contributing.

  • Distinguish: authentication, authorization, roles, and least privilege
  • Know: secret scanning, Dependabot, code scanning, 2FA, and secure secrets
Final review

Can you say it plainly?

Use these prompts without looking anything up. A clear answer is a better signal than recognition.

Exam-day lens

Last pass: practice explaining why an option fits, not just what the option is called.
